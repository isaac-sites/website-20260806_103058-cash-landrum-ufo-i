## Introduction

No publicly available evidence shows that chromosome testing ever confirmed that the Cash–Landrum witnesses received a significant dose of ionising radiation. Supportive accounts of the case have long referred to chromosome testing or chromosome damage, but no laboratory report, methodology, raw data, numerical chromosome-aberration counts or independent expert interpretation has been released for scientific or medical scrutiny. That absence matters because chromosome-aberration analysis is one of the most important biological methods for estimating [radiation dose]({{ 'radiation-dose/' | relative_url }}) when no physical dosimeter was present. If convincing results existed and were available for review, they would represent some of the strongest evidence for radiation exposure. Instead, the claim rests on references to unpublished testing whose findings cannot be independently evaluated.

## How chromosome damage can estimate radiation dose

Chromosome-aberration analysis, often called biological dosimetry, examines blood lymphocytes for characteristic chromosome changes produced by ionising radiation. The best-established method counts unstable abnormalities known as dicentric chromosomes, while fluorescence in situ hybridisation (FISH) can identify stable chromosome translocations that persist for longer periods after exposure. These techniques are internationally recognised tools for reconstructing radiation dose following suspected accidents.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.gov.uk/government/publications/radiation-doses-investigated-by-chromosomal-aberration-analysis-2016-to-2023/doses-in-radiation-accidents-investigated-by-chromosomal-aberration-analysis" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: GOV.UK">[gov.uk]</a><span class="citation-popover" role="note"><span class="citation-popover-source">GOV.UK</span><span class="citation-popover-title">Doses in radiation accidents investigated by chromosomal aberration analysis</span><span class="citation-popover-snippet">Doses in radiation accidents investigated by chromosomal aberration analysis</span></span></span>

## What has been claimed about the witnesses' testing

Over the years, UFO literature and interviews have asserted that chromosome studies were performed on one or more of the witnesses and that abnormalities were reportedly found. However, these accounts consistently stop short of providing the information needed for scientific evaluation.

Publicly available descriptions do not disclose:


<div class="content-enhancement content-enhancement--comparison" markdown="1">

* which laboratory performed the testing;
* which cytogenetic technique was used;
* how many cells were examined;
* whether dicentric chromosomes, translocations or another endpoint was measured;
* the estimated absorbed dose;
* confidence intervals or statistical uncertainty;
* comparison with unexposed controls; or
* whether the findings underwent independent peer review.

</div>

Without these details, the reported testing cannot be assessed against accepted standards for biological dosimetry. References to "chromosome damage" alone are insufficient because chromosome abnormalities can arise from many sources and must be interpreted within a validated analytical framework.

Importantly, no peer-reviewed publication describing chromosome results from the Cash–Landrum witnesses has entered the scientific literature despite decades of interest in the case.

## Why unpublished results cannot settle the case

Biological dosimetry is not simply a matter of detecting any chromosome abnormality. Modern practice requires careful laboratory methods, quality control and statistical interpretation.

Specialists evaluating suspected radiation exposure normally report measurable quantities such as:


<div class="content-enhancement content-enhancement--caution" markdown="1">

* the frequency of dicentric chromosomes;
* the calibration curve used for dose estimation;
* uncertainty ranges;
* the interval between exposure and blood sampling;
* technical limitations that could affect interpretation.

</div>

Without these elements, it is impossible for independent experts to determine whether observed abnormalities, if any, were compatible with a medically significant radiation dose.

Radiation biodosimetry also has recognised limitations. Small numbers of chromosome abnormalities can produce large statistical uncertainties, while delayed sampling, partial-body exposure and individual biological variation complicate dose estimation. Consequently, even genuine chromosome findings require careful interpretation rather than being treated as automatic proof of exposure.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://researchportal.ukhsa.gov.uk/en/publications/limitations-associated-with-analysis-of-cytogenetic-data-for-biol/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchportal.ukhsa.gov.uk">[UK Health Security Agency]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchportal.ukhsa.gov.uk</span><span class="citation-popover-snippet">UK Health Security AgencyLimitations associated with analysis of cytogenetic data for biological dosimetry - UK Health Security AgencyOct...</span></span></span>

## Why the missing data matter in this case

The Cash–Landrum incident is unusual because the alleged radiation exposure was never accompanied by a documented physical measurement of radiation dose. No verified environmental measurements, contaminated materials or personal dosimeters were available to reconstruct exposure.

That makes biological evidence especially important. Had chromosome-aberration testing demonstrated a substantial absorbed dose consistent with the reported illnesses, it would have provided an independent line of evidence supporting the radiation hypothesis.

Instead, the publicly available record contains only assertions that testing occurred, without the underlying documentation needed for verification. As a result:


<div class="content-enhancement content-enhancement--metric" markdown="1">

* the results cannot be independently reproduced or reviewed;
* no dose estimate can be evaluated;
* no comparison can be made with recognised radiation-accident cases;
* the claimed findings cannot be weighed against alternative medical explanations.

</div>

This evidential gap has remained unchanged despite the case's prominence within UFO literature.

## The current evidential assessment

From a medical and scientific perspective, the chromosome-testing question remains unresolved rather than supportive.

The strongest evidence available shows that chromosome-aberration analysis is indeed one of the most reliable biological indicators of significant radiation exposure when properly performed and documented.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pubmed.ncbi.nlm.nih.gov/10838805/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pubmed.ncbi.nlm.nih.gov">[nih.gov]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pubmed.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Improvement of accuracy of chromosome aberration analysis for biological radiation dosimetry - PubMed...</span></span></span>

However, in the Cash–Landrum case, no reviewable laboratory report demonstrating such evidence has been publicly produced. Consequently, chromosome testing cannot presently be cited as confirmation that the witnesses received a radiation dose capable of explaining their reported illnesses.

The distinction is important. The issue is not whether chromosome testing could have answered the question—it is one of the best available methods for doing so. Rather, the problem is that the purported results have never been released in a form that allows independent scientific assessment. Until such documentation becomes available, chromosome testing remains an often-cited but unverified element of the case rather than confirmed biological proof of radiation exposure.

    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
</script>
